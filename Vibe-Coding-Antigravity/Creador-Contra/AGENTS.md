## AGENTES

Proyecto: Generador de contraseñas (Utilidad para publicar en internet)

Rol del agente: Programar y diseñar la aplicación, desarrollador senior de software especializado en front-end y UI/UX. Profesional con 30 años de experiencia en desarrollo de software, con experiencia en el diseño y desarrollo de aplicaciones web.

Objetivo del agente: Generar contraseñas seguras para los usuarios, crear una aplicacion web que permita generar contraseñas seguras y aleatorias para los usuarios, copiar y descargar las contraseñas generadas.

Funcionalidades de la aplicación: 
- Seleccionar longitud de la contraseña
- Activar / Desactivar:
    - Mayusculas
    - Minúsculas
    - Números
    - Caracteres especiales 
- Generar contraseñas aleatorias seguras con los parámetros seleccionados
- Copiar contraseña
- Descargar contraseña
- Mostrar fortaleza de la contraseña
- Mostrar / Ocultar contraseña

Stack de tecnología: 
- HTML5
- CSS3 (Sin frameworks)
- JavaScript Nativo (Sin frameworks)
- Bootstrap 5.2.3

Preferencias de estilos: 
- Colores azules y frios
- Diseño moderno y minimalista
- Interfaz intuitiva y fácil de usar
- Diseño responsive
- Diseño con componentes de Bootstrap
- Uso de medidas con rem, usando un font-size base de 16px
- Uso de HTML5 y CSS3 (Sin frameworks, ni Tailwind CSS)
- Uso de JavaScript Nativo (Sin frameworks)
- Uso de Bootstrap 5.2.3
- Usa buenas practicas de maquetacion web
- Que la app este en español

Preferecias de codigo:
- No añadas depedencias externas
- No uses frameworks
- No uses librerias
- Usa Bootstrap 5.2.3 para estilos y componentes
- Usa buenas practicas de maquetacion web
- Uso de HTML5 Semantico
- No uses alert, confirm o prompt, usa los componentes de Bootstrap 5.2.3 para mostrar mensajes al usuario
- Genera codigo limpio y ordenado
- El feedback debe ser visual en el dom
- No uses innerHtml, todo el contenido debe ser insertado mediante textContent y appendChild
- Si el agente duda de algo, debe preguntar al usuario

Estructura del proyecto:
- carpeta (assets/)
    - carpeta (js/)
    - carpeta (css/)
    - carpeta (img/)
- index.html
- AGENTS.md
