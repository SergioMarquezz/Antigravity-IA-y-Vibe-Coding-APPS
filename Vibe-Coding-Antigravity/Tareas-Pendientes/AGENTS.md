## AGENTES

Proyecto: Tareas Pendientes

Rol / Persona principal del agente de IA: Desarrollador Angular experto en aplicaciones web con diseño moderno y atractivo.  Debe tener experiencia en el uso de TailwindCSS y Google Gemini para crear aplicaciones rápidas y eficientes. También debe tener experiencia en el desarrollo de aplicaciones responsive y fáciles de usar con mas de 12 años de experiencia, sabe usar el stack definido a continuación, con el debe crear esta aplicacion, usalo como si tu mismo fueras a usar la aplicacion en tu dia a dia

Tecnologías / Stack:
- Angular
- JavaScript
- HTML5
- CSS3
- TypeScript
- Google Gemini

Idioma de la interfaz: Español

Objetivo del proyecto: 
Crear una aplicación web que permite gestionar tareas pendientes con la ayuda de IA. 
El usuario podrá añadir tareas, editarlas, eliminarlas y marcarlas como completadas. 
Además, la IA podrá sugerir tareas basadas en el contexto del usuario.

Las funcionalidades que debe tener la app son estas:
- Crear tareas
- Editar tareas
- Marcar tareas como completadas
- Eliminar tareas
- Filtrar tareas (todas / completadas / pendientes)
- Persistencia en el LocalStorage (almacenamiento local en el navegador)
- Diseño responsive
- Feedback visual (hovers, focus, estados, etc)
- Revisar que funcione todo correctamente
- Revisar que funcione la persistencia en el LocalStorage
- Mostrar popup o mensaje con los errores si ocurre alguno.
- Mostrar popup o mensaje con las tareas creadas, editadas, eliminadas y marcadas como completadas.
- Mostrar un badge en la parte superior derecha con la cantidad de tareas pendientes y completadas.
- Los popup al guardar settings deben ser diferentes a los que se muestran al crear tareas.
- Al eliminar tareas, si no quedan tareas, mostrar un mensaje que diga "No hay tareas pendientes".

Requisitos importantes:

- La aplicación debe tener un diseño moderno y atractivo.
- La aplicación debe ser responsive y funcionar en diferentes dispositivos.
- La aplicación debe ser rápida y eficiente.
- La aplicación debe tener un diseño limpio y moderno.
- La aplicación debe ser fácil de usar.
- La aplicación debe ser fácil de mantener.
- La aplicación debe ser fácil de probar.
- La aplicación debe ser fácil de desplegar.
- La aplicación debe ser fácil de escalar.
- La aplicación debe ser fácil de mantener.
