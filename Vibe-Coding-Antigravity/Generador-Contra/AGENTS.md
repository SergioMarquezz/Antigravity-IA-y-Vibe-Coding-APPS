## AGENTS

Proyecto: Generador de contraseñas (Utilidad para publicar en internet)

Rol del agente: Desarrollador wer experto con 12 años de experiencia

Objetivo: Crear una aplicación web que gener contraseñas aleatorias y seguras

Funcionalidades de la aplicación:

- Seleccionar longitud
- Activar / Desactivar:
    - Mayusculas
    - Minusculas
    - Caracteres especiales
- Generar contraseñas aleatorias
- Copiar contraseñas al portapeles
- Indicador de fortaleza de la contraseña
- Mostrar / Ocultar contraseña

Stack de tecnologia:
- HTML5
- CSS3 (Sin frameworks)
- JavaScript (vanilla, sin frameworks )
- Bootstrap5.3.3

Preferencias de diseño:
- Moderno
- Responsivo
- Minimalista
- Claro

Preferencias de estilos:
- Colores azules y frios
- Uso de medidas con rem, usando un font-size base de 10px
- Uso de HTML5 y CSS3 nativo (sin tailwind, ni frameworks)
- Usa buenas practicas de maquetación css y si es necesario usa flexbox y css grid layout
- La aplicación debe estar en español
- La aplicación debe ser responsive

Preferencias de código:
- No agregues dependencias externas
- HTML debe ser semantico
- No uses alert, confirm, prompt, todo el feedback debe ser visual en el dom
- No uses innerHTML, todo el contenido debe ser insertado con appendChild o previamente creando un elemento con document
- Cuidado con olvidar prevenir el default de los eventos en submits o clicks
- Prioriza el codigo legible y mantenible
- Prioriza que el codigo sea sencillo de entender
- Si el agente tiene duda, que revise las especificaciones del proyecto y si no que pregunte al usuario

Estructura de archivos:
- Carpetas(assents)
    - carpeta(css)
    - carpeta(js)
    - carpeta(img)
- index.html
- AGENTS.md
- LEGEND.md
- README.md
